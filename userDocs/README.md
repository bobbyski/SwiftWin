# SwiftWinUI User Documentation

Welcome to the SwiftWinUI user documentation.

SwiftWinUI is an experimental SwiftUI-compatible framework for building native Windows desktop apps in Swift. The current prototype can open a native Win32 window, render basic text and stack layouts, show owner-drawn buttons, route button actions, display native dialogs, and print the view tree through a console renderer.

## Current Status

SwiftWinUI is an early prototype. It is useful for exploring architecture and Swift-on-Windows UI mechanics, but it is not production-ready.

The long-term goal is maximum practical SwiftUI compatibility, with `SwiftWinLegacy` developed simultaneously as the traditional imperative foundation underneath or beside the declarative layer.
